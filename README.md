# TravelTrucks

TravelTrucks is a web application for browsing and renting campers. Users can explore the catalog, filter campers by different criteria, view detailed information about each camper, and submit a booking request.

## Features

- Browse a catalog of campers
- Filter campers by:
  - Location
  - Vehicle type
  - Transmission
  - Engine type
- Load More pagination
- View detailed camper information
- Responsive design for desktop, tablet, and mobile devices
- Fast data fetching with TanStack Query
- Booking request form

## Technologies

- Next.js
- React
- TypeScript
- TanStack Query
- Axios
- CSS Modules

## Installation

1. Clone the repository:

```bash
git clone https://github.com/LudSkop/TravelTrucks.git
```

2. Navigate to the project folder:

```bash
cd TravelTrucks
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open your browser and go to:

```
http://localhost:3000
```

## Build for Production

```bash
npm run build
npm start
```
